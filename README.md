# Hashir Portfolio

Vite + vanilla JS + Three.js portfolio.

## Develop
```
npm install
npm run dev
```

## Build
```
npm run build
npm run preview
```

## Structure
- `index.html` — markup/sections
- `src/main.js` — wires up loader, nav, hero scene, work cards, skills, reveals, contact form
- `src/three/heroScene.js` — Three.js hero background (layered MERN stack visualization)
- `src/data.js` — content: projects + skills
- `src/style.css` — all styling
